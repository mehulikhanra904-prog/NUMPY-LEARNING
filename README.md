# NumPy Learning 🧮

A beginner-friendly repository documenting my hands-on journey with **NumPy**, the fundamental Python library for numerical computing. This project contains small programs and practice exercises covering arrays, indexing, mathematical operations, filtering, random values, and matrix calculations.

> Learning by doing — building strong Python and numerical-computing foundations step by step.

## 🚀 What You'll Find Here

| File | Concepts covered |
|---|---|
| `numpy.np` | Creating 1D, 2D and 3D arrays; array attributes; indexing; slicing; replacing values; zeros, ones, full and random arrays; copying |
| `operations_practice.np` | Element-wise arithmetic, comparison operators, array shapes and matrix multiplication |
| `numpy_practice.py` | Mathematical functions, scalar operations, slicing, aggregation, matrix multiplication and trigonometric functions |
| `filtering.py` | Boolean indexing, filtering values by conditions, even/odd selection and `np.where()` |
| `random_numbers.py` | Generating random integers with NumPy's random Generator |
| `tasks_practice.py` | Broadcasting and statistical functions such as sum, mean, standard deviation, variance, minimum and maximum |

## 🧠 Topics I'm Practicing

- **Array fundamentals:** `np.array()`, dimensions, shape, size and data types
- **Array creation:** `zeros()`, `ones()`, `full()` and random arrays
- **Indexing & slicing:** Selecting elements, rows, columns and sub-arrays
- **Array operations:** Addition, subtraction, multiplication and division
- **Vectorized mathematics:** Square root, exponential, logarithmic and trigonometric functions
- **Filtering:** Boolean masks, comparison conditions and `np.where()`
- **Matrix operations:** Shape compatibility and `np.matmul()`
- **Broadcasting:** Performing operations on arrays with compatible shapes
- **Statistics:** Mean, sum, standard deviation, variance, minimum and maximum

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/mehulikhanra904-prog/NUMPY-LEARNING.git
cd NUMPY-LEARNING
```

### 2. Install NumPy

Make sure Python 3 is installed, then run:

```bash
python -m pip install numpy
```

### 3. Run a practice file

For example:

```bash
python numpy_practice.py
python filtering.py
python random_numbers.py
python tasks_practice.py
```

Files with the `.np` extension contain Python code too. You can run them by passing the filename to Python:

```bash
python numpy.np
python operations_practice.np
```
